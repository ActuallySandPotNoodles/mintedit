A basic text editor wrote in C++

## Installing

`curl -s https://raw.githubusercontent.com/ActuallySandPotNoodles/mintedit/refs/heads/main/install.sh | sudo bash`

This will automatically select your platform (x86_64/aarch64)

I'll make an arch package and epkg package soon

## Features

- Openning files via command (or open with)
- Replace words
- View line amount
- Preview HTML and Markdown
- Open directorys

## Building

1) Clone the repo
   
2) Create `/build` and navigate into it
   
3) Build it with

`cmake ..`

`make`

4) The build executable should then appear in the `build` directory
